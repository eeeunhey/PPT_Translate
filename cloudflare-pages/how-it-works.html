🤖 AI 번역 기술 소개

PPT Translator는 최신 AI 기술을 활용하여 PowerPoint 파일의 한국어 텍스트를 영어로 자동 번역합니다. 단순한 단어 치환이 아닌, 문맥을 이해하는 지능형 번역을 제공합니다. 이 페이지에서는 번역 엔진의 기술적 원리를 소개합니다.

⚙️ 번역 파이프라인

하나의 PPTX 파일이 업로드되면, 아래 4단계 파이프라인을 거쳐 번역된 파일이 생성됩니다.

1

📄 PPTX 파싱 및 텍스트 추출

PPTX 파일은 실제로 XML 기반의 압축 파일입니다. 서버는 이 파일을 해제하고, 각 슬라이드의 XML 구조를 분석하여 모든 텍스트 상자, 표, 도형 내의 텍스트를 추출합니다.

  • 텍스트의 위치, 크기, 스타일(폰트, 색상, 굵기 등) 정보도 함께 저장
  • 그룹화된 도형 내부의 텍스트도 재귀적으로 탐색
  • 표(Table) 셀 단위의 텍스트 추출
2

🔍 한국어 감지 및 필터링

추출된 모든 텍스트에 대해 유니코드 범위 분석을 수행합니다. 한글 음절(U+AC00~U+D7AF) 또는 한글 자모(U+3130~U+318F)가 포함된 텍스트만 번역 대상으로 분류합니다.

  • 영어만 포함된 텍스트는 원문 유지 → 불필요한 번역 비용 절약
  • 숫자, 특수문자, URL 등은 번역하지 않고 보존
  • 한영 혼합 텍스트의 경우 전체 문맥을 고려하여 번역
3

🧠 AI 배치 번역

번역 대상 텍스트를 효율적인 배치(batch) 단위로 그룹화한 뒤, AI 번역 엔진에 전달합니다. 이 과정에서 다음 기술이 적용됩니다:

  • 문맥 인식 번역: 단어가 아닌 문장/문단 단위로 의미를 파악
  • 전문 용어 처리: 비즈니스, 기술, 학술 분야의 전문 용어를 인식
  • 번역 근거 생성: 각 번역에 대해 직역/의역 여부와 단어별 의미 분해를 함께 생성
  • 미번역 감지: 번역이 불가능하거나 원문 유지가 적절한 경우를 자동 판별
4

🎨 디자인 보존 PPT 생성

번역된 텍스트를 원본 PPTX 파일에 삽입하여 새 파일을 생성합니다. 이때 원본의 모든 디자인 요소를 100% 보존합니다:

  • 레이아웃: 텍스트 상자 위치, 크기, 정렬
  • 서식: 폰트, 크기, 색상, 굵기, 기울임
  • 이미지/차트: 삽입된 이미지, 차트, SmartArt 보존
  • 애니메이션: 슬라이드 전환, 개체 애니메이션 유지
  • 마스터 슬라이드: 배경 테마, 색상 구성표 보존

🔒 보안 및 프라이버시

PPT Translator는 사용자의 데이터 보안을 최우선으로 합니다.

  • HTTPS 암호화: 모든 통신은 TLS로 암호화되어 전송됩니다
  • 자동 삭제: 업로드된 파일은 번역 완료 즉시 서버에서 삭제됩니다
  • 번역 결과 임시 보관: 다운로드용 번역 파일은 일정 시간 후 자동 삭제됩니다
  • 로깅 최소화: 파일 내용은 로그에 기록하지 않으며, 처리 메타데이터만 기록합니다
  • 제3자 공유 없음: 업로드된 파일은 번역 처리 목적으로만 사용됩니다

🔮 향후 계획

  • 영한 번역 (영어 → 한국어) 지원 예정
  • 다국어 번역 (일본어, 중국어 등) 확장
  • 배치 처리 (여러 파일 동시 번역)
  • 번역 메모리 (이전 번역 결과 재활용)
  • 용어집 커스터마이징 (사용자 정의 전문 용어)
