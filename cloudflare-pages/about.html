PPT Translator 소개

PPT Translator는 PowerPoint 프레젠테이션을 한국어에서 영어로, 영어에서 한국어로 자동 번역하는 무료 온라인 서비스입니다. 원본 디자인을 100% 보존하면서 빠르고 정확한 번역을 제공합니다.

🎯 왜 만들었나요?

한국어로 작성된 PowerPoint 자료를 영어로 번역해야 할 일이 자주 있었습니다. 매번 슬라이드를 하나씩 열어 텍스트를 복사 → 번역기에 붙여넣기 → 다시 PPT에 입력하는 과정이 너무 비효율적이었습니다. 특히 표, 차트, 그룹 도형 안의 텍스트까지 일일이 수작업으로 바꾸다 보면 시간도, 정확도도 떨어졌습니다.

"파일 하나만 올리면 디자인은 그대로 유지하면서 자동 번역되면 좋겠다"

이 간단한 아이디어에서 PPT Translator가 탄생했습니다. 🚀

✨ 주요 기능

🎨 원본 디자인 100% 보존

폰트, 색상, 레이아웃, 표, 차트까지 모든 디자인 요소를 그대로 유지합니다. 번역 후에도 원래의 프레젠테이션 품질이 그대로 유지됩니다.

👥 듀얼뷰 미리보기

원본과 번역을 나란히 비교하며 실시간으로 결과를 확인할 수 있습니다. 슬라이드별로 원문과 번역문을 테이블 형식으로 비교할 수도 있습니다.

🔍 번역 근거 제공

단어별 의미 분해와 번역 방식(직역/의역)을 함께 확인할 수 있습니다. 번역 결과가 왜 이렇게 나왔는지 투명하게 보여줍니다.

📊 표와 차트 완벽 지원

일반 텍스트뿐 아니라 복잡한 표, 차트, 그룹 도형 내부의 텍스트도 정확하게 추출하고 번역합니다.

🎯 미번역 감지

번역되지 않은 항목을 자동으로 감지하고 하이라이트하여, 놓친 부분이 없도록 도와줍니다.

🔒 파일 보안

업로드된 파일은 번역 처리에만 사용되며, 처리 완료 후 서버에서 자동 삭제됩니다. 파일 내용을 저장하거나 제3자에게 공유하지 않습니다.

📖 사용 방법

  1. 파일 업로드 — .pptx 파일을 드래그 앤 드롭하거나 클릭하여 업로드
  2. 자동 번역 — AI 엔진이 텍스트를 추출하고 번역
  3. 결과 확인 — 슬라이드별 미리보기, 상세 비교, 번역 근거 확인
  4. 다운로드 — 번역된 .pptx 파일 다운로드

🔧 기술 스택

  • Backend: Python, Flask, python-pptx
  • Translation Engine: Google Translate (자동 Fallback: MyMemory)
  • Frontend: HTML, CSS, JavaScript
  • Hosting: Cloudflare Pages (Frontend) + Private Server (Backend)
