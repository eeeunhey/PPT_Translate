📘 PPT 번역 완벽 가이드

PPT Translator를 처음 사용하시나요? 이 가이드를 따라하면 누구나 쉽게 한국어 PowerPoint를 영어로 번역할 수 있습니다. 파일 업로드부터 결과 다운로드까지, 모든 과정을 단계별로 안내합니다.

📋 시작하기 전에

지원 파일 형식

  • .pptx 파일만 지원합니다 (Microsoft PowerPoint 2007 이상)
  • .ppt 형식은 PowerPoint에서 .pptx로 변환 후 업로드해 주세요
  • Google Slides나 Keynote 파일은 먼저 .pptx로 내보내기 후 이용 가능합니다

파일 크기 제한

  • 최대 50MB까지 업로드 가능
  • 일반적인 프레젠테이션(30~50슬라이드)은 대부분 이 제한 내에 포함됩니다
  • 이미지가 많은 파일은 PowerPoint에서 이미지 압축 후 업로드하면 용량을 줄일 수 있습니다

🚀 번역 과정 단계별 안내

1

파일 업로드

메인 페이지의 업로드 영역에 .pptx 파일을 드래그 앤 드롭하거나, "파일 선택하기" 버튼을 클릭하여 파일을 선택합니다.

파일명에 한글이 포함되어 있어도 정상적으로 업로드됩니다. 파일명은 보안을 위해 서버에서 자동으로 안전한 이름으로 변환됩니다.
2

자동 번역 진행

파일이 업로드되면 AI 번역 엔진이 자동으로 작업을 시작합니다. 아래 3단계를 거칩니다:

  1. 텍스트 추출 — 슬라이드 내 모든 텍스트 상자, 표, 도형에서 텍스트를 추출합니다
  2. 한글 감지 및 번역 — 한국어가 포함된 텍스트만 선별하여 영어로 번역합니다
  3. 번역 PPT 생성 — 원본 디자인을 유지하면서 번역된 텍스트로 새 파일을 생성합니다

진행 상황은 실시간으로 화면에 표시되며, 경과 시간도 함께 확인할 수 있습니다.

3

결과 확인 — 듀얼뷰 미리보기

번역이 완료되면 원본과 번역본을 나란히 비교할 수 있는 미리보기가 나타납니다.

  • 슬라이드 미리보기: 원본 슬라이드와 번역된 슬라이드를 시각적으로 비교
  • 테이블 비교: 텍스트 단위로 원문과 번역문을 테이블로 상세 비교
  • 번역 근거: 각 텍스트의 번역 방식(직역/의역)과 단어별 의미 분해 확인
  • 미번역 감지: 번역되지 않은 항목은 노란색으로 하이라이트 표시
4

번역 파일 다운로드

"번역 파일 다운로드" 버튼을 클릭하면 .pptx 형식의 번역된 파일을 받을 수 있습니다.

다운로드 후 일정 시간이 지나면 서버에서 파일이 자동 삭제됩니다. 번역 결과가 만족스러우면 즉시 다운로드해 주세요!

✨ 더 나은 번역 결과를 위한 팁

1. 텍스트 상자를 활용하세요

이미지에 포함된 텍스트(예: 스크린샷 속 한글)는 인식하지 못합니다. 번역이 필요한 텍스트는 반드시 텍스트 상자에 입력되어 있어야 합니다.

2. 표(Table) 내 텍스트도 번역됩니다

슬라이드 내 표에 입력된 한국어도 자동으로 감지하고 번역합니다. 표의 형식과 스타일은 그대로 유지됩니다.

3. 영어가 섞여 있어도 OK

한국어와 영어가 혼합된 텍스트도 정상적으로 처리됩니다. AI가 한국어 부분만 선별하여 영어로 번역하므로, 기존 영어 텍스트는 그대로 유지됩니다.

4. 번역 후 검수를 권장합니다

AI 번역은 매우 높은 정확도를 제공하지만, 전문 용어나 맥락에 따라 수정이 필요할 수 있습니다. 중요한 발표 자료의 경우 번역 결과를 한번 검토하시는 것을 권장합니다.

🔧 문제가 발생했나요?

파일 업로드가 안 될 때

  • 파일 확장자가 .pptx인지 확인해 주세요
  • 파일 크기가 50MB를 초과하지 않는지 확인해 주세요
  • 브라우저를 새로고침한 후 다시 시도해 주세요

번역 결과가 부정확할 때

  • 전문 용어가 포함된 경우 AI가 일반적인 의미로 번역할 수 있습니다
  • 약어나 줄임말은 원문 그대로 유지될 수 있습니다
  • 번역 근거를 확인하여 어떤 방식으로 번역되었는지 파악할 수 있습니다

다운로드가 안 될 때

  • 번역 완료 후 너무 오래 지나면 파일이 서버에서 삭제될 수 있습니다
  • 이 경우 파일을 다시 업로드하여 번역해 주세요
